# Old-World Battle Calculator

**Old-World Battle Calculator** is a rando-created tool designed to simulate and calculate random outcomes using mechanics given by _Warhammer: The Old World_, a tabletop wargame developed by **Games Workshop**.

This application does **not** include or reproduce any copyrighted content from Games Workshop, such as rulebook text, lore, or proprietary artwork. Instead, it provides a framework for players to explore and experiment with probability and mechanics based on publicly observable gameplay behavior, such as dice-based combat resolution and statistical interactions between units.
